## 一、买入参数详解

参数	     说明

资金账号	         |你的券商资金账号，8 位数字

授权码	         |必填，格式 DBP-XXXXXXXXXX-YYYYMMDD-XXXX-XXXXXXXX

监控板块		      |QMT 里自建的板块名，策略只监控这个板块里的票

每日最大买入数	    |	一天最多买几只，建议 1~3 只，控制风险

买入方式		      |按金额（固定金额）/ 按股数（固定手数）/ 按仓位（资金占比）

单票买入金额		|按金额模式下每只票花多少钱，例如 5000

单票买入股数      |按股数模式下买多少股，必须是 100 的倍数

仓位百分比		   |按仓位模式下，用可用资金的百分之几

心跳间隙	         |几秒判断一次，1 秒最快，3 秒更稳（建议 1~3）

监控开始时间	   |几点开始监控，格式 09:30:00（英文冒号）

监控结束时间      |几点停止监控，建议 14:57:00

剔除ST		     |勾选后自动跳过 ST、*ST 股票

A_强势扫板买	   |涨幅到设定值就用涨停价委托，抢在封板前买入

扫板涨幅    	   |模式触发线，例如 9.6 表示涨到 9.6% 就开枪

B_智能排板买	   |已涨停且封单金额大于阈值，挂涨停价排队

排板买一金额大于	 | 模式的封单门槛，单位万元

C_板上排测买	  |封单在[min, max]区间内才排板，避开封单过大或过小的票

排板买一金额下限  | 模式封单下限（万）

排板买一金额上限	|模式封单上限（万）

排板撤单阈值	  |封单掉到该值以下就撤单（万）

排板超时撤单      |挂单超过多少秒没成交就撤单

是否为调试模式	   |勾选后只打印日志不下单，首次使用建议勾选，注意实盘取消勾选

调试日志		      |输出详细判断过程，排查问题时打开

## 二、卖出参数详解

参数	           说明

监控板块    	  |只管这个板块里的持仓，留空表示管理全部持仓

心跳间隙	        |几秒判断一次

卖出价格类型	  |笼子下沿（推荐）买一价×98% / 买一价 / 对手方最优 / 五档市价 / 跌停价

卖出比例	        |每次卖多少，100=全部，50=一半

封板撤单卖出	  |持仓还在涨停，但封单掉太多就卖（说明资金撤退）

封板撤单金额	  |封单低于这个值就卖（万）

止损卖出    	  |跌破成本就卖

止损百分比	     |跌多少触发，例如 3 表示亏 3% 止损

止盈卖出	        |盈利达到阈值就卖

止盈百分比	      |赚多少触发

开板未回封卖出  	|涨停被打开，N 分钟内没回封就卖

开板分钟数	      |开板多长时间算未回封

竞价盈利清仓   	|次日竞价时，盈利达到阈值就全部卖掉

竞价盈利阈值	   |盈利百分之几触发清仓

竞价不及预期卖出	|次日竞价跌幅达到阈值就卖

竞价不及预期阈值	|跌幅达到这个值触发，例如 -2

冲高回落卖出	  |先涨到目标涨幅，再回落到设定值就卖

冲高目标涨幅	  |第 1 个值：涨幅先要达到这个数

回落到涨幅    	|第 2 个值：从高点跌回这个涨幅就卖

竞价触发时间	 |几点判断竞价，一般是 09:24:55

冷却时间	       |卖出后多少秒内不再重复判断，0=当天不再管

是否为调试模式	 |只打印不下单，注意实盘取消勾选

调试日志	      |输出详细判断过程
